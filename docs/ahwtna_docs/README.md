## 🎯 القواعد الأساسية السريعة لدومينو 101
- **المجموعة:** Double-Six من 28 قطعة فريدة.
- **التوزيع:** 7 قطع لكل لاعب (في الفردي والزوجي).
- **الفردي (2P):** 14 قطعة في مخزون السحب؛ يسحب اللاعب قطعة تلو الأخرى عند غياب النقلة حتى يجد حركة أو ينفد المخزون؛ وإذا نفد يمرّر إجبارياً.
- **الزوجي (4P):** تُوزع الـ 28 قطعة كاملة، ولا يوجد سحب نهائياً؛ يمرّر اللاعب فوراً عند غياب النقلة.
- **الإغلاق (القفلة):** يحدث عندما لا يملك أي لاعب في الطاولة حركة قانونية؛ صاحب (أو فريق) المجموع الأقل يفوز، والتعادل بلا نقاط.
- **الخسارة:** الطرف الذي يبلغ رصيده التراكمي 101 نقطة أو أكثر يخسر الماتش فوراً.
